# Retail Stockwise

Open `Retail Stockwise.html` in a browser. Keep `retail_sales_data.js` in the same folder so the bundled analytics and dataset-loading feature work.

The original 1,000-row source is preserved as `retail_sales_dataset.csv`. The app includes a Retail Dataset tab and seeds the sales history from that data. The source does not supply current inventory or supplier costs, so inventory begins at zero and COGS uses clearly labelled category estimates (Beauty 55%, Clothing 60%, Electronics 70% of sale price). Replace the Bought at values in Stock with your actual supplier costs whenever they are available.
